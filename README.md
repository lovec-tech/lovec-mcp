# lovec-mcp

Локальный MCP-сервер поверх детектора промпт-инъекций [lovec.tech](https://lovec.tech).
Даёт агентам (Claude Desktop, Claude Code, любой MCP-клиент) тул `check_prompt_injection` —
проверка недоверенного текста (веб-страница, документ, результат тула, письмо) перед тем,
как отдать его в другую LLM.

Работает **только с вашим собственным ключом** — сервер ничего не хранит и не шарит,
это тонкий клиент поверх уже существующего API-ключа/баланса с сайта.
Никакого обхода монетизации: сколько запросов сделаете — столько спишется с вашего баланса,
ровно как при прямых вызовах API.

## Установка

```bash
cd lovec-mcp
python3 -m venv .venv
./.venv/bin/pip install -e .
```

Ключ берётся на [lovec.tech](https://lovec.tech) (регистрация → стартовые кредиты
или пополнение баланса).

## Быстрая проверка руками

```bash
export LOVEC_KEY=aig_...
./.venv/bin/python server.py
```

Процесс молча висит и ждёт MCP-клиента на stdin/stdout — это нормально, Ctrl+C для выхода.
Для проверки логики без реального MCP-клиента:

```bash
export LOVEC_KEY=aig_...
./.venv/bin/python -c "
import asyncio, server
print(asyncio.run(server.check_prompt_injection('тестовый текст')))
"
```

## Подключение к MCP-клиенту

Claude Desktop (`claude_desktop_config.json`) или Claude Code (`.mcp.json`) — один и тот же формат:

```json
{
  "mcpServers": {
    "lovec": {
      "command": "/absolute/path/to/lovec-mcp/.venv/bin/python",
      "args": ["/absolute/path/to/lovec-mcp/server.py"],
      "env": { "LOVEC_KEY": "aig_..." }
    }
  }
}
```

Абсолютные пути обязательны — MCP-клиент запускает команду не из этой директории.

## Переменные окружения

| Переменная | По умолчанию | Зачем |
|---|---|---|
| `LOVEC_KEY` | — (обязательна) | ключ с lovec.tech |
| `LOVEC_BASE` | `https://lovec.tech` | другой хост API |
| `LOVEC_TIMEOUT` | `60` | потолок ожидания одного вызова, секунды |

## Известные ограничения

- **Латентность API непредсказуема.** Замеры 31 авг 2026 на живом сервисе: один и тот же
  вызов отрабатывал за 2.2 с и за **173.7 с**. Поэтому в сервере стоит жёсткий потолок общего
  времени (`LOVEC_TIMEOUT`, по умолчанию 60 с) — иначе агент повисает на минуты. Важный нюанс:
  штатный `timeout=` у httpx считает паузу МЕЖДУ БАЙТАМИ, а не общую длительность, и такой
  запрос он не обрывает; потолок сделан через `asyncio.wait_for`.
- **Домен API уже переезжал.** `promptidote.tech` теперь 301-редиректит на `lovec.tech`
  (действующий хост уже в дефолте `LOVEC_BASE`). Клиент собран с `follow_redirects=True`
  на случай следующего переезда — httpx по умолчанию редиректы не проходит, и без этого
  флага сервер тихо получал бы страницу редиректа вместо ответа API.
- Лимит текста — 5000 символов на вызов (ограничение самого API); длиннее — дробить на части
  на стороне вызывающего. Проверка локальная, лишний запрос к API не тратится.
- `score` калиброван неидеально: бимодальный, но заметно чаще ложно срабатывает на длинном
  оценочном/рассуждающем тексте (отзывы, спорная проза), чем на коротком фактическом —
  не блокировать жёстко по одному `is_injection` без учёта контекста.
- Это детектор инъекций, не авторизация — RBAC/права доступа он не проверяет и не заменяет.

## Публикация

Локально сервер полностью рабочий. Этот репозиторий (`github.com/lovec-tech/lovec-mcp`)
и есть верифицированный namespace для публикации в [MCP Registry](https://modelcontextprotocol.io/registry/about)
и другие каталоги (mcp.so, smithery.ai, glama.ai). Сама подача в реестры — следующий шаг,
ещё не сделана.
